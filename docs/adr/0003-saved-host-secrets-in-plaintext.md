# Saved Host secrets are stored in plaintext for now

Saved Hosts keep their password, private key and passphrase in the users SQLite database as plaintext. We considered encrypting them with a key from `.env`, which makes a stolen database file useless on its own, and with a key derived from the User's password, which hides secrets even from whoever runs the server but loses them on a password reset and needs the key kept between requests although sessions are only signed cookies (see 0002). Both were postponed to keep the first iteration simple; encryption with a key from `.env` is the intended next step. Until then a copy of the database, including backups of the `webssh-data` volume, gives access to every Saved Host, so the database file is created readable only by webssh and the README warns about it.
